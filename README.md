The fleshing out and development of a long imagined game concept in the spirit of the Microprose game "Carrier Command".

I am using AI to build and code this, so don't hate on me - please, it's just me and I am in control, and it's just me coding at the moment. I am very aware of AI slop and I don't want this to be that.

This will begin as a single player game, with a plan to build a multi-player framework in the future.

A Jupiter-scale water-planet is randomly generated once, saved in a perpetual state in Postgresql database, graphic with Babylonjs, built with node, vite, and whatever else is needed while keeping modules and hooks to a minimum.
